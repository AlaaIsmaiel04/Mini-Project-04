# Mini Project 04

A team project developed by six members.

**Status: Awaiting teacher selection**

Our team has proposed the following four ideas. The teacher will
choose one for us to develop.

## 1. SmartShelf — Pharmacy Inventory & Expiry Tracker

A web application that helps pharmacies manage medicine stock and
reduce waste from expired products. Staff can register medicines
and batches, track quantities and expiry dates, and view alerts
for medicines approaching expiration. The system suggests using
the earliest-expiring stock first and provides a dashboard with
inventory summaries.

## 2. QuestRoom — Cooperative Online Escape Game

A multiplayer web game where players work together to solve puzzles
before time runs out. Each player receives different clues, making
communication essential. The application includes private rooms,
interactive puzzles, a shared inventory, hints, and team scores.

## 3. StoryFork — Interactive Story Platform

A web application where writers create stories with choices that
lead to different paths and endings. Readers make decisions, save
their progress, and discover alternative outcomes. Writers can use
a visual editor to connect scenes and see which choices readers
make most.

## 4. SkillSprint — Creative Challenge Platform

A web application where users join short challenges in photography,
writing, design, or programming. Participants submit their work
before a deadline, exchange feedback, and earn badges. Organizers
can create challenges, define judging criteria, and publish results.
