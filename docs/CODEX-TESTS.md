# اختبارات بواسطة Codex

جُمعت ملفات الاختبار في آخر commit حسب طلب مصطفى، بعد commits التنفيذ المرتبطة بأيام خطة المهام. هذه أرقام أيام الخطة، وليست ادعاءً بأن العمل نُفّذ في تواريخ مختلفة.

| الملف                                                | التغطية / أيام الخطة                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `apps/api/src/common/business-date.spec.ts`          | اليوم 3 و11: توقيت عمّان، التواريخ الحقيقية، حدود انتهاء الصلاحية والمؤشرات                                             |
| `apps/api/src/common/subscription-status.spec.ts`    | اليوم 3 و9: حالات الاشتراك وحدود البداية والنهاية والتعليق                                                              |
| `apps/api/src/common/inventory-calculations.spec.ts` | اليوم 11: حسابات المخزون؛ الاختبار الأصلي من محمد، جمّعه وشغّله Codex دون تغيير نسبته                                   |
| `apps/api/src/inventory.integration.spec.ts`         | الأيام 8–12: JWT والملكية، قراءة الاشتراك غير الفعّال، المدخلات والتكرار، الفلاتر، rollback، إعادة تشغيل API وعميل علاء |
| `scripts/test-integration.mjs`                       | تشغيل اختبارات القبول على PostgreSQL منفصل                                                                              |
| `scripts/smoke.mjs`                                  | تحديث الفحص الموجود لبدء التطبيق، Swagger، حماية المخزون وواجهة الإنتاج                                                 |

```powershell
npm run typecheck
npm test
npm run build
npm run smoke
npm run test:integration
```

اختبارات قاعدة البيانات تحتاج `TEST_DATABASE_URL` لقاعدة اسمها `smartshelf_test` أو `smartshelf_test_<suffix>`. إعداد جهاز مصطفى موجود في `.local/test.env` وهو غير مرفوع. لا تستخدم الاختبارات قاعدة التطوير كبديل، ولا تنفّذ reset. اقرأ [إعداد التشغيل](LOCAL-SETUP.md) و[نتائج التنفيذ والتحقق](MUSTAFA-IMPLEMENTATION.md).

نتائج التحقق: 431 اختبار API و5 اختبارات واجهة ناجحة؛ مجموعة PostgreSQL متخطاة في `npm test` وتعمل منفصلة عبر `test:integration` الذي نجحت اختباراته العشرة. البناء وtypecheck وsmoke نجحت. فحص التنسيق الشامل يحتوي مخالفات سابقة في 91 ملفاً خارج هذا التغيير؛ ملفات هذا التغيير منسّقة.

لم تُعلّم اختبارات بقية أعضاء الفريق على أنها من إنشاء Codex. ملفات البيئة، كلمات المرور، قاعدة البيانات المحلية ونتائج التشغيل المؤقتة ليست ضمن commits الاختبارات.
